# 🌐 Template-2 – HTML, CSS & JS

This is a **single-page website** built from the [Kasper One Page PSD Template](https://www.graphberry.com/item/kasper-one-page-psd-template).

I was inspired and guided by [Osama Elzero](https://www.youtube.com/@ElzeroWebSchool) – you can check his video about this template [here](https://youtu.be/heuDmrEAgUA?si=5rx1_AZtMjOFNKoo).

---

## 🚀 Features

-   Fully responsive design using **HTML5 & CSS3**
-   Clean, modern **one-page layout**
-   Smooth scrolling navigation
-   Added **JavaScript file** with new custom features:
    -   Dynamic interactions
    -   Extra animations & enhancements
    -   Improved user experience
